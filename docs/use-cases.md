# Kite use cases

## Explore a company theme

A user interested in AI, semiconductors, healthcare, strategic systems, or another theme can start with a curated basket, inspect every constituent and allocation, and decide whether to learn more about the individual assets before taking action.

## Make a first investment safely

Paper mode gives a new user a complete product walkthrough with virtual USD: browse, buy, inspect a portfolio, review activity, and create a recurring paper plan. The simulation is clearly separated from wallet settlement.

## Buy or swap a tokenized equity

An experienced Solana user can select a funded wallet token, search for a destination asset, review the Jupiter route and minimum output, and approve a transaction from the wallet. Stock-to-stock swaps are supported where the route and asset checks pass.

## Build a basket in one approval

Instead of manually placing one order per company, a user can review the target allocation for a basket. Kite validates all legs and, when supported by the route and transaction limits, asks the wallet to approve one atomic transaction.

## Invest periodically

A user can authorize a finite daily, weekly, or monthly plan for a stock or basket. The plan records its terms, has a hard expiry, and can be revoked. Actual unattended execution requires an operator to configure and run the buyer-controlled service; the app does not pretend that a scheduled UI alone guarantees delivery.

## Monitor an onchain portfolio

Kite reads wallet-owned SPL and Token-2022 accounts directly from Solana, aggregates holdings, identifies frozen or spendable amounts, and preserves unknown tokens rather than hiding them when metadata or valuation is unavailable.

## Who Kite is for

Kite is for crypto-native investors who want a simpler interface for tokenized equity markets, and for curious investors who want to understand the workflow before connecting a wallet. It is not a substitute for regulated brokerage advice, tax advice, or a guarantee of access to any underlying security.
