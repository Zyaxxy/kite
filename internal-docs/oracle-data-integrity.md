# Oracle data integrity

The legacy SDK Pyth registry was verified against the live [official Hermes feed catalog](https://hermes.pyth.network/v2/price_feeds) on 13 September 2026. The registry now contains separate exact `Crypto.<ticker>X/USD` and `Equity.US.<ticker>/USD` identities for AAPL, AMZN, GOOGL, META, MSFT, NVDA, SPY and TSLA. It previously contained invalid identifiers and an AMZN reference that identified SOL/USD.

These identifiers establish feed identity only. They do not establish a token mint, current availability, corporate-action conversion ratio or executable swap price. The applications do not use this registry to replace missing token prices with underlying stock prices.

The on-chain helper now derives the account under Pyth's Push Oracle program and validates its Receiver owner, PriceUpdateV2 discriminator, full verification, exact feed and publication age before accepting a price. It returns no price for failed checks and `unknown` market status for valid observations; publication freshness alone does not prove that a market is open. Its conservative publication limit is 60 seconds. Implementations that need different freshness policies should explicitly configure them in a future API rather than silently accept stale observations. Account derivation and layout follow the official [Solana SDK address definitions](https://github.com/pyth-network/pyth-crosschain/blob/main/target_chains/solana/sdk/js/pyth_solana_receiver/src/address.ts), [PDA derivation](https://github.com/pyth-network/pyth-crosschain/blob/main/target_chains/solana/sdk/js/pyth_solana_receiver/src/PythSolanaReceiver.ts) and [PriceUpdateV2 type](https://github.com/pyth-network/pyth-crosschain/blob/main/target_chains/solana/pyth_solana_receiver_sdk/src/price_update.rs).

The legacy issuer-oracle adapter requires an explicitly configured HTTPS endpoint and returns an empty result when unavailable. It does not manufacture issuer observations or confidence policies from static identifiers. Legacy Jupiter responses preserve unknown token precision; unavailable Meteora fees and volume remain `null` rather than looking like measured zeroes.

Before deploying an oracle consumer, configure the appropriate authenticated provider and supported deployment addresses using the current [Pyth Solana integration guidance](https://docs.pyth.network/price-feeds/core/use-real-time-data/pull-integration/solana). A successful public metadata query does not prove that a price stream is available without authentication. Provider credentials belong on the server.

Regression coverage: `packages/sdk/test/oracle-integrity.test.cjs` verifies distinct token/reference identities, exact symbol selection, account validation and absence of fabricated fallback observations.
